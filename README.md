# synaesthetic

Личная полка ароматов: у каждого флакона своя песня и своя картинка. Веб-приложение на three.js; на телефоне ставится на домашний экран как PWA.

Что входит в MVP, описано в `synaesthetic-perfumerie.md` (в репозитории прошлой итерации). Дизайн-система: https://claude.ai/artifact/KuCoSDWkF4qjAQtHoBzoa8

## Запуск

Нужен Node.js 20+ (на этой машине портативный: `C:\Users\Sasha\nodejs`).

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173. С телефона в той же сети Wi-Fi: адрес из строки `Network` в выводе.

## Устройство

- `src/data` — модель (флакон, пара, трек) и хранилище в браузере (IndexedDB). Всё хранение идёт через `db.ts`, поэтому позже его можно заменить на сервер с аккаунтами.
- `src/shelf` — полка конвертов на three.js: текстуры рисуются на canvas, кадры перерисовываются только во время движения.
- `public/models/shelf.glb` — стена и полка из Blender с запечённым светом. Пустышки (Empty, тип Cube) в файле — места для конвертов: тонкая сторона — толщина конверта. Код читает всё из файла, после переэкспорта ничего менять не нужно. Draco-декодер лежит в `public/draco`.
- `public/env/wooden_studio_08_1k.hdr` — студия, которой освещена сцена в Blender (Poly Haven, CC0), уменьшенная с 4K EXR. Ею же освещены конверты.
- `src/ui` — форма добавления (флакон → песня → обложка), смена песни.
- `src/images` — уменьшение фото, вырезка белого фона для стикера, палитра.
- `src/audio` — чтение тегов загруженного трека (ID3 в MP3: название, исполнитель, обложка; иначе имя файла).
- `src/styles/tokens.css`, `components.css` — копии из дизайн-системы. При изменении системы их нужно обновить.
- `server/api.ts` — разбор ссылок (og-теги, oEmbed Spotify/YouTube/SoundCloud, прокси картинок). В разработке работает внутри Vite, на опубликованном сайте — как Netlify Function (`netlify/functions/api.ts`, `netlify.toml`). Вариант для Cloudflare тоже есть (`worker/`, `wrangler.toml`).

## Известные ограничения

- Fragrantica и Золотое Яблоко не пускают серверные запросы (защита от ботов). Тогда бренд и название угадываются по адресу ссылки, фото добавляется вручную: перетащить или вставить скриншот.
- Яндекс Музыка не отдаёт данные о треке без браузера: исполнителя и песню вписывают сами.
- Публичное API Odesli (song.link) закрыто, поэтому поиска того же трека на других платформах пока нет.
- Внутри приложения играют только загруженные с устройства файлы (пока пластинка вынута из конверта). Песни по ссылке открываются в сервисе через «Слушать ↗». Файлы хранятся в браузере (IndexedDB) вместе с остальной полкой.
